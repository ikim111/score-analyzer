# 정오표 분석기 (score-analyzer)

NEIS 정기시험 **학생답 정오표(.xlsx)** 를 브라우저에 끌어다 놓으면 문항분석·점수분포·반별 비교·영역별 분석을 계산하고, ChatGPT 등 AI에 바로 붙여넣을 글을 만들어 주는 단일 HTML 도구입니다.

- **1개의 시험 분석하기**: 정답률·변별도·문항-점수 관계·오답지 분석·성적대별 정답률·신뢰도(KR-20)·측정오차·반별 비교·영역별 분석
- **두 시험 비교분석하기**: 같은 학생(학번)끼리 짝지어 변화·상대 위치·신뢰 변화 지수·잔차 이득·성장 백분위·반별 변화
- 파일은 **브라우저 안에서만** 처리되고 어디로도 전송되지 않습니다. AI용 글에는 학생 이름·학번이 들어가지 않습니다.

## 사용
1. NEIS › 성적 › 정기시험교과목별 학생답 정오표 › 반별 엑셀 저장
2. 사이트를 열고 파일들을 상자에 한꺼번에 놓기
3. 맨 아래 "AI에게 붙여넣을 글" 복사 → AI에 붙여넣기

## 배포
정적 파일 하나(`index.html`)라 Vercel/GitHub Pages 어디든 그대로 올리면 됩니다. 외부 의존성은 SheetJS(cdnjs)와 Google Fonts뿐입니다.
